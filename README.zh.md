# 浣熊垃圾场幸存者 (Raccoon Survivors)

> 一款浣熊主题的 survivors-like，一杯咖啡的时间就能打完一局。单文件 HTML5、零依赖、任意浏览器即开即玩——或[直接在 GitHub Pages 上试玩](https://tjj1234.github.io/raccoon-survivors/)。

## 这是什么

《浣熊垃圾场幸存者》是一款轻量 **survivors-like + 连携卡牌** 混合游戏。你只管走位，游戏自动开火，在越来越凶的"垃圾怪"潮里活下去。通关一局、攒下永久成长，下一局走得更远。

## 怎么玩

- **在线：** https://tjj1234.github.io/raccoon-survivors/
- **离线：** 下载 `index.html` 双击即玩。

## 核心玩法

- **自动开火 + 走位** 基础循环——WASD / 方向键移动，准星跟随鼠标自动开火。
- **主动大招（空格）**：全屏清场爆发，被围殴时的救命按钮。
- **tag 连携系统**：卡牌带 tag，相同 tag 叠加乘数（实时版 Balatro 连携层）。
- **成长树**：根基 / 武器 / 配装 三档永久强化，支持**随时免费重洗**。
- **敌人多样化 + Boss 弹幕**：随关卡升级越来越狠。
- **爽感反馈**：大数字、连杀、震屏、慢镜终结。

## 操作

| 按键 | 动作 |
|------|------|
| WASD / 方向键 | 移动 |
| 鼠标 | 瞄准（自动开火） |
| 空格 | 大招 |
| P | 暂停 |

## 技术

纯 HTML5 Canvas + 原生 JavaScript，全部塞进单个 `index.html`。无需构建、无依赖、可离线运行。
