# Raccoon Survivors

> A trash-panda survivors-like you can finish in one coffee break. Single-file HTML5, zero dependencies, runs in any browser — or [play it now on GitHub Pages](https://tjj1234.github.io/raccoon-survivors/).

## What is it

**Raccoon Survivors (浣熊垃圾场幸存者)** is a compact *survivors-like* + *synergy-deck* hybrid. You move, the game auto-fires, and you survive escalating waves of junk-themed enemies. Clear a run, bank permanent upgrades, and push further next time.

## Play

- **Online:** https://tjj1234.github.io/raccoon-survivors/
- **Offline:** download `index.html` and double-click it.

## Features

- **Auto-fire + dodge** core loop — move with WASD / arrows, aim follows your cursor.
- **Active ultimate** (`Space`): a screen-clearing burst. Your panic button when swarmed.
- **Tag synergy system**: cards carry tags; matching tags stack multipliers — a real-time, Balatro-style combo layer.
- **Meta progression tree**: three tiers (*Foundation* / *Weapons* / *Build*) of permanent upgrades, with **free respec** anytime.
- **Varied enemies + bullet-hell bosses** that escalate by level.
- **Juicy feedback**: big damage numbers, kill streaks, screen shake, and slow-mo finishers.

## Controls

| Key | Action |
|-----|--------|
| WASD / Arrows | Move |
| Mouse | Aim (auto-fire) |
| Space | Ultimate |
| P | Pause |

## Tech

Pure HTML5 Canvas + vanilla JavaScript in a single `index.html`. No build step, no dependencies, works offline.
